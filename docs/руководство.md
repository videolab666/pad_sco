# Руководство: что нового и как этим пользоваться

> Обновлено после Шагов 0–2 (план-4 §248): корты стали сущностями с любыми
> именами, появились вечные ссылки /c/{код}, QR-запуск игр, дашборд клуба,
> вход для персонала. Старые привычные вещи не изменились.

## 1. Корт теперь — карточка, а не цифра

Раньше корты были числами 1–10, зашитыми в код. Теперь у каждого корта есть
**имя** (любое: «Центральный», «Корт спонсора», «VIP»), и он живёт в списке,
который вы редактируете сами.

**Где:** `/settings` → вкладка **«Корты»** (вход — тот же пароль, что на
главной, или логин персонала — см. §7).

- **Добавить корт** — введите имя, нажмите «Добавить». Поле «slug» можно не
  трогать, заполнится само.
- **Переименовать** — поправьте имя в строке, нажмите галочку.
- **Сослаться/поделиться** — кнопка вида `/c/Ab3xK9Q` копирует **вечную
  ссылку** корта.
- **Убрать корт** — значок архивации: корт исчезает из списков, но история
  матчей остаётся. «Показать архив» → вернуть обратно.

## 2. Вечная ссылка /c/{код}

Распечатайте её в **QR и повесьте на корт**. Эта ссылка не устаревает НИКОГДА:
переименование корта её не меняет. Открывается на любом экране:

- **идёт матч** → живое табло (счёт, сеты, подача);
- **матч закончился** → результат последнего матча;
- **матчей не было** → заставка с кнопкой «Быстрая игра».

Подходит для: ТВ на корте (браузер в полноэкранном режиме), vMix/OBS
(browser source), QR для игроков.

## 3. Быстрая игра — игроки запускают матч сами

Игрок сканирует QR корта → «⚡ Быстрая игра» → вводит **4 имени**: начинает
печатать — подтягиваются игроки из вашей базы; если имени нет в базе, человек
станет «гостем». Кнопка **«Перемешать»** случайно делит на пары.
**«Начать игру»** — табло корта включается само.

Попутно создаётся **сессия корта** — запись «кто, когда и на каком корте
играл» (основа будущей статистики и рейтингов).

## 4. Дашборд клуба — весь клуб одним взглядом

**`/dashboard`** — сетка карточек: кто на каком корте, счёт, длительность
матча, свободные корты, бейджи «AMERICANO / ТРЕНИРОВКА». Обновляется сам
каждые 10 секунд — **повесьте экран в ресепшн**. Из `/settings` туда ведёт
кнопка «Дашборд кортов».

## 5. Создание матча — выбор корта по имени

В `/new-match` вместо зашитой сетки 1–10 теперь список ваших кортов (занятые
зачёркнуты). Если интернет пропал — автоматически показывается старая сетка
1–10, ничего не ломается.

## 6. vMix / OBS — старое работает, новое добавилось

| Что | Ссылка |
|---|---|
| Как раньше (не тронуто) | `/api/court/1`, `/fullscreen-scoreboard/1`, `/api/vmix/{id}` |
| JSON по коду корта (вечная) | `/api/v1/courts/Ab3xK9Q/vmix` — есть поле **`court_name`** |
| Состояние корта (сессия+матч) | `/api/v1/courts/Ab3xK9Q` |
| Весь клуб одним запросом | `/api/v1/dashboard` |

## 7. Вход для персонала (новый, пока необязательный)

- **Как раньше** — паролем на главной: работает.
- **Новый способ** — страница `/login` (email + пароль). Учётки выдаёт
  администратор одной командой:

  ```
  node scripts/create-admin.mjs ivan@club.com пароль owner
  ```

  Роли: `owner / manager / referee / coach / viewer`
  (viewer — только смотрит, кнопок не получает).
- Когда всем выдадите логины — старый пароль уберём.

## 8. Пароль на главной теперь настраивается

Раньше в коде был зашит «111». Теперь он берётся из файла **`.env.local`**
(строка `SETTINGS_PASSWORD=111`). Хотите сменить — поменяйте строку и
перезапустите приложение. Без этой строки вход в настройки закрыт совсем.

## 9. Что НЕ изменилось

Подсчёт очков, undo, таймеры, физические кнопки, реклама на табло,
трансляции — всё работает как раньше. Все старые ссылки живы.

## 10. Чего пока нет (честно)

- кнопки «перенести существующий матч на другой корт» в UI;
- управления сессиями корта из UI (пока API);
- прямой записи в БД из браузера (закроем на Шаге 3 — command pipeline).
